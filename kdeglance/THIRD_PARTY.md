# Third-party components and media

KDEGlance's own source is GPL-3.0-or-later, selected with the project owner's
explicit approval. The complete text is in LICENSE. This source release does
not redistribute Qt/KDE binaries or a prebuilt activation bridge.

| Component | Use / licensing |
| --- | --- |
| PyQt6 | System dependency; GPL v3 or Riverbank commercial license. This open-source distribution uses the GPL-compatible route. PyQt is not LGPL. |
| Qt 6 | System dependency, not bundled; individual Qt modules retain their upstream LGPL/GPL/commercial terms. |
| KDE WindowSystem | Dynamically linked system dependency; installed public headers identify LGPL-2.1-or-later. Bridge source is included and rebuilt locally. |
| Mutagen 1.48.1 | Bundled pure-Python source; GPL-2.0-or-later. Upstream COPYING, metadata, authors and provenance are retained in kdeglance/vendor/. This component can be used under GPL v3 terms in this GPL v3 project. |
| PyGObject/Gio, GLib, AT-SPI, D-Bus, systemd, Dolphin/KIO Fuse | System dependencies; not vendored/relicensed by this archive. Their installed packages retain upstream notices. |
| FFmpeg/codecs | Used by the system multimedia backend and optional fixture generator; no FFmpeg executable/library is included. Codec availability varies with the system. |
| Control icons / placeholder | Project-drawn vector primitives in visuals.py. No third-party icon-pack files or supplied design-sheet bitmap are distributed. |
| Test media and screenshots | Original geometric artwork, color bars, sine tones, and captures of the real application using those assets; generated by the included scripts. GPL-3.0-or-later with the project. No downloaded photos or commercial recordings. |
| Fonts | System fonts only; no font files are bundled. |

Mutagen wheel provenance and hash are recorded in `kdeglance/vendor/SOURCE.json`;
its original GPL text is under `mutagen-1.48.1.dist-info/licenses/COPYING`.
Do not remove upstream notices when redistributing the source.
