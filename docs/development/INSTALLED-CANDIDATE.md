# Установка проверочного кандидата 1.0.0-4

28 октября 2026. Владелец явно подтвердил установку 1.0.0-4 вместо 1.0.0-3.
Обновление выполнено через pacman/Polkit. Версия проекта остаётся 1.0.0;
это не подтверждение финальной приёмки и не разрешение версии/релиза 2.0.0.

После установки подтверждены:

- `pacman -Q kdeglance`: 1.0.0-4.
- `pacman -Qkk kdeglance`: 64 файла, 0 изменённых.
- SHA256 установленного бинарника совпадает с проверенным stripped-бинарником пакета.
- Настоящая D-Bus/systemd-активация, скрипт KWin и плагины Dolphin из /usr
  без QT_PLUGIN_PATH; Space открывает изображение, навигация синхронизирует выделение.
- Ещё 20 циклов через установленный Bridge: успешно; NRestarts=0.
- Установленный просмотрщик показал TXT, PDF и DOC/DOCX/DOCM/RTF/ODT/OTT/FODT,
  подтверждена готовая растровая страница PDF, а не только завершение конвертера.
- Реальное указанное SMB-видео воспроизводится с декодированными кадрами;
  после Close проигрыватель остановлен, кадр очищен, окно скрыто.
- Установленная служба использует libqwayland.so. Предупреждения повторного
  создания ресурсов KWindowShadow в журнале отсутствуют.

Тестовое окно Dolphin закрыто. Пользовательские окна Dolphin не закрывались;
ранее открытые окна следует перезапустить для загрузки обновлённых плагинов.
Служба оставлена в штатном состоянии без открытого предпросмотра.

Физические Alt-drag/Alt-resize, плавность и прекращение слышимого звука должны
быть подтверждены владельцем по [чек-листу](MANUAL-ACCEPTANCE.md).
До этого версия 2.0.0 не назначается. Публикация не выполнялась.

- build/desktop/candidate-installed-journal.log
