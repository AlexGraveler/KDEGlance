## Причины и исправления

- **IMG-01:** после декодирования всегда включалась подгонка, пользовательский масштаб
  не сохранялся. Добавлен необязательный `image.zoom` в существующий Settings/JSON.
  Пишутся только явные действия масштабирования. Автоматическая подгонка не перезаписывает
  выбранное значение. Новое изображение использует его с согласованной геометрией окна,
  ограниченной рабочей областью; при большом масштабе остаётся панорамирование.
  Без сохранённого значения остаётся прежний первый показ 100%/вписать большой снимок.
- **VID-01:** видеоповерхность перекрывает MediaView; неявной передачи событий QWidget
  недостаточно. Её события явно направляются в существующие обработчики MediaView и
  ContentView, затем в прежнюю навигацию ViewerApp/Dolphin. Кнопки и ползунки исключены.
- **VID-02:** в исходниках была одна кнопка вращения и похожая круглая кнопка повтора.
  Повтор получил две прямые стрелки и отдельное имя; функция повтора сохранена.
  Поворот остался один, с подсказкой «90° против часовой стрелки». Проверены цвета
  кадра после четырёх шагов, размеры, метаданные, сохранение zoom и работа перемотки.
- **TXT-01/02:** убраны меню кодировки, кнопки и рамка редактора. Чтение остаётся только
  для просмотра. Автоопределение: BOM/валидный UTF-8, NUL-полосы UTF-16 без BOM,
  оценка структуры кириллических слов для Windows-1251/KOI8-R/CP866 с запасным Windows-1252.
- **TXT-03 / PDF-02:** общий фильтр области документа вызывает тот же
  `ContentView::requestWindowMove()` → `QWindow::startSystemMove()`, что изображения
  и видео. Обычный/Alt-drag перемещает, Shift-drag оставляет выделение; Ctrl+A/C сохраняют
  выделение и копирование без контекстного меню. Полосы прокрутки
  не перехватываются, глобальные настройки KWin не изменяются.
- **TXT-04:** для угловых событий два прохода обычного Qt-обработчика сохраняют
  накопление мелких шагов. Qt 6.12 игнорирует pixel-only события QPlainTextEdit:
  добавлен путь с точным коэффициентом 2 и целочисленным остатком пикселей, без потери
  мелких событий и ошибок округления. Текстовый редактор прокручивается по строкам,
  Markdown — по пикселям. Другие модули не ускоряются.
- **PDF-01:** убраны панель и внутренние рамки. Страницы, прокрутка, кэш и рендеринг
  сохранены. `Ctrl+колесо`, `+`/`−` — масштаб, `F`/`0` — ширина, `R` — Reflow/страницы.
  Офисные документы наследуют чистый интерфейс встроенного PDF.

В Markdown `M` переключает исходник/форматирование. Следующие 8 МиБ текста
подгружаются у конца прокрутки или по `Ctrl+PageDown`. Состояние Reflow доступно
во всплывающей подсказке документа, без постоянной панели.

## Ограничения проверки

Настоящий графический сеанс доступен: CachyOS, Plasma/KWin Wayland, Qt 6.12,
Dolphin 26.08, NVIDIA RTX 4070 SUPER, один экран 2560×1440 / 100%.
Тестовый адаптер посылает события Qt в настоящие окна; это не физический ввод
Wayland. Сам факт вызова startSystemMove проверяется, но захват окна композитором,
плавность физического drag/Alt-resize и субъективная прокрутка требуют ручной проверки:
[MANUAL-ACCEPTANCE.md](MANUAL-ACCEPTANCE.md).

Однобайтовая кодировка без маркировки неоднозначна; автоматическая оценка не может
гарантировать правильное чтение любого короткого или смешанного текста. Исходные
байты не изменяются. Пиксельные события тачпада на текстовом редакторе накапливаются
до высоты строки; субстрочная анимация не заявляется. Reflow ограничен первыми 2 МиБ
текста, упрощает форматирование и не выполняет OCR. Multi-monitor/HiDPI и
длительная физическая интерактивная нагрузка не проверены.

## Повторение графического прогона

Адаптер включается только для тестов (`-DBUILD_DESKTOP_TEST_ADAPTER=ON`) и не
устанавливается пакетом. Используются синтетические медиа, созданные генераторами:

```sh
tests/formats/generate_samples.sh build/desktop/candidate-samples
python tests/documents/generate-samples.py build/desktop/candidate-samples
ffmpeg -y -f lavfi -i testsrc2=size=640x360:rate=25 -f lavfi -i sine=frequency=440 -t 8 -c:v mpeg4 -c:a aac build/desktop/candidate-samples/long-video.mp4
# Установить KDEGLANCE_TEST_SMB_URL на свой разрешённый тестовый SMB-файл.
python tests/desktop/check-stage2.py
```

Перед прогоном закрыть собственное окно предпросмотра: сценарий откажется
останавливать службу с открытым пользовательским просмотром. Настройки теста
отдельные; завершаются только собственные тестовые Dolphin, а штатная служба
восстанавливается. Код возврата ненулевой при любой отмеченной ошибке.
