# Разработка перед приёмкой 2.0.0

Версия остаётся 1.0.0 до выполнения обязательных условий и подтверждения владельца.

Контрольная точка: checkpoints/before-document-development.tar.gz.
Локальная история Git: .development-history (обычный .git недоступен/пуст).
Команды истории: git --git-dir=.development-history --work-tree=. log / diff.

1. Восстановить точное управление из GitHub; исправить масштаб/размеры, Alt-drag.
2. Перемотка на прогресс-баре, поворот/масштаб видео, надёжная остановка,
   состояния загрузки и ошибок.
3. Асинхронное разрешение сетевых URL через KIO/FUSE с отменой и очисткой.
4. Текстовый просмотр с потоковым чтением/кодировками и Markdown.
5. Непрерывный PDF через Poppler с ограниченным кэшем и фоновым рендерингом.
6. Офисные документы через отдельный headless-профиль LibreOffice,
   отключённые макросы/обновление ссылок, затем встроенный PDF.
7. Регрессионные тесты, документы-образцы, локальный и настоящий SMB,
   сборка Pacman и отдельные окна настоящего Dolphin/Wayland.
8. Ручная приёмка пользователем. Только после неё: версия 2.0.0 и пакет 2.0.0-1.

Репозиторий-источник схемы управления: https://github.com/AlexGraveler/KDEGlance
В нём Python 1.0.1; локальный проект C++ — другая реализация. Схема управления
переносится без замены существующей C++ архитектуры и без копирования движка.
