# Временный зум и Enter — 28 октября 2026

Версия приложения и пакета сохранена: **1.0.0-5**. Установленный пакет не заменяется
без отдельного согласования. Полноэкранный режим, интерфейс и архитектура не переделаны.

## Исправления

- Настоящее пользовательское изменение размеров через края окна по-прежнему
  сохраняет `window.sizes.image` существующим Settings. При следующем открытии фото
  эти размеры восстанавливаются с ограничением доступной областью экрана.
- Колесо и клавиши масштаба меняют только изображение внутри окна. Нет обратного
  изменения геометрии через displaySizeChanged; зум больше не записывается в JSON.
  При unload/закрытии он сбрасывается. Новое фото вписывается в восстановленное окно
  без принудительного увеличения маленького оригинала. Без сохранённой геометрии
  сохраняется натуральный размер с вписыванием большого снимка в рабочую область.
- Устаревший `image.zoom` из 1.0.0-5 удаляется при миграции настроек текущей схемы.
  Размеры окон и остальные значения остаются. Неизвестные ключи будущей схемы
  по-прежнему сохраняются.
- Return и Enter цифровой клавиатуры обрабатываются общим PreviewWindow раньше
  дочерних виджетов. Сначала закрывается предпросмотр и останавливаются плеер,
  декодеры, конвертер и загрузка. Затем передаётся исходный `PreviewItem.url`.
  Временный путь KIO/FUSE или PDF офисного конвертера не подменяет исходный URL.
- `DefaultFileOpener` использует асинхронный `KIO::OpenUrlJob`: MIME, приложение
  по умолчанию, сетевой доступ и стандартный Open With определяются KDE. Собственной
  таблицы расширений/программ нет. Сервис продолжает работать.
- Дополнительно устранено автозавершение Qt после последнего KIO job: для
  резидентного ViewerApp отключён quit-lock. Отдельный процесс residentopenprobe
  с настоящим QApplication::exec воспроизвёл ошибку до исправления; обычный qExec
  с вложенными циклами её не обнаруживал.
- Автоповторы и события после закрытия игнорируются; одинаковые незавершённые
  запросы запуска объединяются. Если стандартная ассоциация ведёт обратно в
  KDEGlance, показана ошибка вместо повторного предпросмотра. Ошибки KIO показываются
  через немодальный QMessageBox, без `exec()` и остановки обработки D-Bus.
  Незавершённый сетевой запуск ограничен 120 секундами.

## Автоматические проверки

Регрессии зума сначала воспроизведены: колесо меняло 600×400 на 1200×600,
после чего это поведение исправлено. PreviewWindowTest проверяет ручной resize,
сохранение/перечитывание настроек, переход фото → текст → фото, новый снимок с другими пропорциями, ограничение
экраном, временный зум, сброс при закрытии и старый JSON с `image.zoom`.

Добавлен `defaultopentest`: реальные KIO MIME-ассоциации в отдельном XDG-профиле,
системный kbuildsycoca и отдельный процесс-приёмник. Проверены оба Enter в фото,
видео, аудио, TXT, PDF, офисном документе; кириллица и пробелы в пути; остановка
плеера; ровно один запуск; исходный SMB URL после локального разрешения; отсутствующий
файл, отсутствующая программа, рекурсивная ассоциация и следующий успешный запуск.
Локальный путь, переданный приложению KIO вместо file://, нормализуется только в
тесте — это обычное поведение KDE.

Полный CTest: **16/16** (75,60 с), затем выполняется проверка окончательной сборки
пакета. Исходные 15 наборов сохранены, включая AV1/TGA/MIDI, документы и Dolphin.

## Графические проверки

Сценарии: `tests/desktop/check-final-actions.py` (изолированные MIME-ассоциации)
и `tests/desktop/check-system-open.py` (настоящие пользовательские ассоциации).
Адаптер Qt посылает события в настоящие окна Wayland; это не физический ввод
клавиатуры/мыши. Синтетические события не несут Wayland-токен активации: тест
явно выбирает своё окно, а KWin-скрипты временные и выгружаются. В изолированном
профиле отключено закрытие при чужой смене фокуса, чтобы действия пользователя
не мешали проверке Enter; обычные настройки не меняются. Тесты focus-loss остаются.

Первый прогон прервался при блокировке экрана. Блокировка подтверждена через
ScreenSaver.GetActive; владелец разблокировал сеанс, после чего проверка повторена.
Итоговый сценарий `check-final-actions.py`: **94/94** проверки прошли. Проверены
Space/Escape, стрелки и боковые клики видео с настоящим выделением Dolphin;
сохранённая геометрия и старый zoom=8; временное колесо; закрытие и перезапуск
процесса; Enter/цифровой Enter для фото, видео, аудио, текста, PDF и семи офисных
форматов; настоящий SMB с декодированными кадрами и исходным URL на выходе KIO;
остановка плеера; **12** смешанных циклов. Владение D-Bus-именем проверено по PID,
после запусков тот же сервис продолжает отвечать.

Логи: `build/desktop/final2-{resident-reproduced,final-focused-tests,native}.log`;
подробный графический протокол: `build/desktop/final-actions/results.txt`.
`check-system-open.py`: **31/31** проверка настоящих пользовательских ассоциаций
прошла. PNG открыт в Gwenview, TXT — в Kate, MP4 — в VLC, сетевой 3GP — в Haruna.
Приложения определялись по текущему xdg-mime; ассоциации не менялись. Перед запуском
проверялось отсутствие прежних процессов этих приложений. В KWin найдено ровно
одно окно с тестовым именем файла для каждого запуска; закрыты только эти окна.
После каждого Enter сервис оставался жив и отвечал на Ping. Лог:
`build/desktop/final2-system-open.log`, протокол `build/desktop/system-open/results.txt`.

Для PDF/Office открытие через KIO и обоих Enter проверено в изолированном профиле.
Пользовательские Firefox/ChatGPT для этих типов не открывались: их независимые окна
и вкладки не затрагивались. Полноценный физический ввод клавиатуры этим не заменяется.

Окончательный `makepkg`: **16/16** обязательных наборов прошли, 77,97 с.
Извлечённый бинарник пакета: **97 файлов, 0 отказов, 0 обязательных отказов**.
MIDI проверялся с временным FluidR3 через KDEGLANCE_SOUNDFONT; системный SoundFont
