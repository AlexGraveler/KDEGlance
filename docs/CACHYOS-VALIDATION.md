# Проверка KDEGlance на CachyOS — 28 октября 2026

Этот отчёт дополняет и заменяет устаревшие сведения о недоступном рабочем столе
в REPORT.md, TESTING.md и FORMATS.md. Проверки выполнены непосредственно на
CachyOS, Qt 6.12.0, FFmpeg 9.0.2, Dolphin 26.08.2, KWin 6.8.1 Wayland,
NVIDIA RTX 4070 SUPER, один экран 2560×1440, масштаб 100%.

## Найденные причины и исправления

- **TGA:** FFmpeg создавал корректный несжатый TGA. Принудительное
  `setDecideFormatFromContent(true)` приводило к ошибочному выбору ICO по
  неоднозначному заголовку. Для TGA используется штатный выбор по расширению;
  для остальных изображений сохранена проверка содержимого (в частности BMP,
  названных `.dib`). Регрессионный тест проверяет конкретные цвета пикселей
  и отказ на усечённых данных. RLE TGA также проходит.
- **AV1:** установленный Qt выбирал аппаратный декодер, который выдавал ошибки
  Vulkan без видеокадра. До создания первого QMediaPlayer выполняется проверка
  короткого синтетического AV1 в отдельном процессе с тайм-аутом. При отказе
  выбирается программное декодирование для всего процесса. Настройка отключения
  аппаратного декодирования исправлена: Qt требует значение `,`, а не пустую
  строку. Успех проверки кадра требует также успешного `QVideoFrame::toImage()`.
  Добавлен отдельный обязательный тест с принудительным Vulkan.
- **MIDI:** FluidSynth установлен, но системного SoundFont нет. Старая CLI-проверка
  всегда возвращала ошибку, даже не пытаясь синтезировать файл. Теперь проверяются
  обе зависимости; при их наличии MIDI синтезируется во временный WAV и реально
  декодируется. Проверена работа с официальным FluidR3_GM.sf2, распакованным только
  в каталог сборки. Переменная `KDEGLANCE_SOUNDFONT` позволяет явно указать банк.
  При отсутствии зависимостей сообщается точная причина. Формат остаётся
  экспериментальным, обязательные проверки не отключены.
- **Гонка MIDI:** отложенная ошибка отсутствующего синтезатора могла выгрузить
  следующий файл. Добавлена проверка поколения загрузки, включая отложенный
  сигнал готовности видео; обработаны ошибка запуска FluidSynth и невозможность
  создать временный каталог. Временный WAV удаляется после остановки проигрывателя.
- **Настоящий Dolphin:** все ABI-символы находились, но модель файлов была
  переподчинена KItemListController. Поиск только среди непосредственных детей
  DolphinView делал Space неработоспособным. Исправлен поиск модели и списка,
  с сохранением старого варианта и изоляцией разделённых видов. Макет обновлён
  согласно настоящему дереву QObject.
- **Pacman и повторная сборка:** фиксированные даты архива позволяли CMake
  переиспользовать старые объектные файлы после повторной распаковки той же версии.
  PKGBUILD теперь выполняет `cmake --build build --clean-first`: очищаются только
  результаты компиляции, исходники сохраняются.
- **Сборка:** минимальная Qt поднята до 6.8 (используется QAudioBufferOutput).
  При BUILD_TESTING отсутствие Qt Test теперь является ошибкой конфигурации,
  а не причиной молча не собирать тесты. Архиватор исключает служебные каталоги
  окружения, сгенерированные moc/pycache и результаты сборки. pkgrel увеличен до 3.

- **Повторное открытие и тени:** проверка установленного пакета обнаружила
  предупреждения KWindowShadow о setWindow при существующих native resources.
  В updateShadow изменён порядок: destroy → setWindow → create.

## Автоматические проверки

Исходная сборка: 83 образца, 3 ошибки, из них 2 обязательные — TGA и AV1.
MIDI отмечался ошибкой экспериментального формата.

Исправленная сборка: **12/12 наборов CTest проходят**. Это исходные 11 наборов
и новый av1fallback. Новый синтетический DNG проверяет LibRaw без скачивания
пользовательских фотографий. Без SoundFont MIDI по-прежнему честно отображается
как недоступный; это не отменяет обязательных проверок. Отдельный прогон с
временным FluidR3: **84 образца, 0 ошибок**, включая MIDI и синтетический DNG.

Команды:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build -j4
ctest --test-dir build --output-on-failure -j3
KDEGLANCE_SOUNDFONT=/path/to/FluidR3_GM.sf2 \
  QT_QPA_PLATFORM=offscreen build/src/kdeglance --probe-formats build/tests/format-samples
```

Песочница блокировала локальные сокеты D-Bus/PipeWire. Полные прогоны проведены
с разрешённым доступом к этим сокетам; ошибки песочницы не выдавались за ошибки
приложения. Отчёты находятся в `build/desktop/ctest-final.log`,
`formats-with-soundfont.log`, `midi-render.log`, `raw.log`.

## Проверки настоящего рабочего стола

Приложение и настоящие процессы Dolphin запускались из дерева сборки через
QT_PLUGIN_PATH, с отдельным XDG_CONFIG_HOME. Установка пакета не требовалась.
KWin загрузил рабочий скрипт размещения, сообщил рабочую область 2560×1402,
окно просмотра получало фокус. Проверены:

- Space открывает выделенный файл; Space и Escape закрывают;
- стрелки меняют файл, выделение настоящего Dolphin следует за просмотром;
- контекстное меню настоящего Dolphin вызывает просмотр;
- переключение фокуса закрывает окно;
- 30 последовательных циклов открытия и закрытия;
- два настоящих процесса Dolphin: собственный сеанс просмотра для каждого,
  навигация меняет выделение только в исходном окне;
- программное изменение размеров настоящего Wayland-окна;
- JPEG, анимированный GIF, синтетический RAW DNG, AV1 и MP3 в настоящем окне;
- визуально просмотрены снимки AV1 и DNG, полученные из виджета.

**Граница достоверности:** клавиши доставлялись тестовым Qt-адаптером в настоящие
виджеты, а фокус менялся временным KWin-скриптом только для тестовых окон.
Это проверка настоящего приложения и Dolphin в реальном сеансе, но не физический
ввод Wayland. Адаптер не устанавливается; его сборка отдельно включается через
`-DBUILD_DESKTOP_TEST_ADAPTER=ON`. Сценарий: `tests/desktop/run-native-session.py`;
предварительно образцы копируются в `build/desktop/samples/`.
Сценарий следует запускать при отсутствии другой службы KDEGlance и не трогать
клавиатуру во время теста. Подробный журнал: `build/desktop/native-session-final.log`.

## Оставшиеся ограничения и непроверенные пункты

- Нет доступа к физическому вводу мыши: плавность перетаскивания, интерактивного
  resize и Alt-resize, привязка противоположного края KWin не подтверждены.
  Программный resize не должен сохраняться как пользовательский: сохранение
  размеров проверено автотестами, но требует ручного подтверждения после drag.
- Пакет 1.0.0-2 установлен с согласия владельца через Polkit. Подтверждены
  D-Bus/systemd-активация, загруженный скрипт KWin, плагины из /usr без
  QT_PLUGIN_PATH, Space, синхронизация и 20 циклов через Bridge. NRestarts=0.
  Пакет 1.0.0-3 добавляет исправление тени. Выход и повторный вход в Plasma
  не проверены.
- В системе отсутствует SoundFont. MIDI работает с указанным временным банком;
  для повседневного использования нужен soundfont-fluid или другой банк SF2/SF3.
- Положительная проверка RAW использует синтетический DNG. Реальные CR2/CR3/NEF
  и встроенные превью камер в этом прогоне не проверены.
- Один монитор и масштаб 100%: другие экраны и дробное масштабирование не проверены.
- AV1-preflight консервативен: при отказе аппаратного пути всё видео в данном
  процессе декодируется программно; он не доказывает поддержку GPU каждого кодека.
  Проверка добавляет до нескольких секунд к холодному запуску резидентной службы.
- Внутренний ABI Dolphin остаётся архитектурным риском. Наличие символа не
  гарантирует ABI-совместимость возвращаемого типа; переподчинение объектов уже
  продемонстрировало пределы прежних макетов.
- Вывод видео через QVideoFrame::toImage() копирует кадры в RAM; производительность
  4K60, длительное воспроизведение и часы работы здесь не измерялись.
- Сетевые файлы без локального KIO-FUSE пути остаются информационными карточками.
  Полный список редких форматов без генераторов находится в SKIPPED.txt.

Исходники не удалялись, настройки KDE и глобальные сочетания не изменялись,
системные пакеты не устанавливались. Изменения не публиковались и не отправлялись
в GitHub. Итог нельзя считать полной ручной приёмкой всех перечисленных выше
интерактивных сценариев.
