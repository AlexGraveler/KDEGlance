# Итог после установки KDEGlance 1.0.0-3

28 октября 2026, CachyOS, Plasma Wayland. Установка 1.0.0-2 и обновление до
1.0.0-3 выполнены через pacman/Polkit после отдельных подтверждений владельца.
Проверки и код исправлений описаны в [основном отчёте](CACHYOS-VALIDATION.md).

- Финальная сборка Pacman: 12/12 наборов тестов, check() не отключался.
- Финальный stripped-бинарник из пакета: 84 образца, 0 ошибок с временным
  FluidR3_GM.sf2. Системный SoundFont не устанавливался.
- Установлена версия 1.0.0-3. `pacman -Qkk kdeglance`: 42 файла, 0 изменённых.
  SHA256 установленного бинарника совпадает с бинарником из пакета.
- Настоящая D-Bus/systemd-активация, работа службы через libqwayland.so,
  скрипт KWin и плагины из /usr без QT_PLUGIN_PATH подтверждены.
- Space в отдельном настоящем Dolphin открыл изображение с фокусом;
  навигация синхронизировала выделение. Ещё 20 циклов через Bridge прошли,
  NRestarts=0. Предупреждения о ресурсах KWindowShadow после исправления отсутствуют.
- В полном прогоне из дерева сборки: 30/30 циклов с Qt-событиями клавиш,
  Space/Escape, стрелки, контекстное меню, потеря фокуса, два настоящих окна
  Dolphin с независимыми сеансами, JPEG/GIF/DNG/AV1/MP3.
- Изменение syncSelection пережило настоящий перезапуск установленной службы
  через D-Bus/systemd. Исходное значение восстановлено.

Прямой ввод физической мышью недоступен. Плавность перемещения и resize,
Alt-resize и сохранение размера после настоящего drag не объявляются проверенными.
Логика размеров проходит автотесты; программный resize настоящего окна также
проверен. Дробное масштабирование, несколько мониторов, длительная работа,
выход/вход в Plasma и реальные RAW-фотографии камер остаются непроверенными.
Тестовые клавиши — Qt-события в настоящих виджетах, не эмуляция Wayland seat.

Тестовые окна Dolphin закрыты; установленная резидентная служба оставлена для
обычного использования. Открытые до установки пользовательские окна Dolphin
нужно перезапустить, чтобы загрузились плагины. Пользовательские окна принудительно
не закрывались. Глобальные сочетания KWin не менялись; публикаций не было.
