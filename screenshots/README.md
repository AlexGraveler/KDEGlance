# Screenshot provenance

The five PNGs are captures of the actual 1.0.0 Qt widgets, made by
`tests/render_screenshots.py` using Qt's offscreen platform. The controls and
placeholder are the application's own painting code; video comes from the real
QMediaPlayer/QVideoSink. Controls are held visible for capture. These are not
interface mockups and do not show a native desktop/compositor session.

- image-preview.png: original geometric image, controls hidden.
- image-controls.png: the same image after a real wheel zoom event, controls shown.
- audio-cover.png: actual MP3 embedded art, paused playback and controls.
- audio-placeholder.png: WAV without embedded artwork, actual glass placeholder.
- video-preview.png: decoded procedural FFmpeg test clip and real controls.

All underlying media are generated by tests/generate_fixtures.py; no third-party
photos, recordings, movie frames or design-sheet bitmaps are included. The
screenshots and generated media are GPL-3.0-or-later with KDEGlance.
